How publishing works

Three places, one piece of writing.

1. Archive

The public file history lives in GrapheneFacts/graphene-archive. That repo is for storage, diffs, and source links — not for comfortable reading.

Private compile work stays in the private repo and does not go on this site.

2. This site

Readable pages are Markdown files under content/ in GrapheneFacts/quartz. A push to the v5 branch rebuilds graphenefacts.github.io/quartz.

Each essay can link back to the archive file it came from.

3. X

X is distribution. The post should point people here (or to a specific page), not replace the write-up.
