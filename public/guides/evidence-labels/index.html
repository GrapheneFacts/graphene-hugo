Evidence labels

Label Use when Standing list
Well-supported Peer-reviewed paper, official regulator text, confirmed commercial order —
Preliminary Preprint, company lab data, pilot/small-cell results —
Unverified / Unsourced Assertion without solid primary source [[logs/unsourced]] (subsection of [[logs/conspiracies]])
Fringe Conspiracy-style narratives; document only [[logs/conspiracies]]

Unsourced is not automatically Fringe. A missing citation is a source problem. A cover-up story is a narrative problem. They can attach to the same sentence; the labels stay separate.

Folder placement (research, industry, fringe, unverified, …) is for browsing. The label is for confidence.
